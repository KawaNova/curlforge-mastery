# Release Notes - v1.0.0

### 日本語 (ja-JP)
🎉 『JWTインスペクター (JWT Inspector)』初回公式リリース！
- 外部送信ゼロ・100%端末内オンデバイスで安全にJWTトークンをデコード
- Header（赤）・Payload（紫）・Signature（青）の3色ハイライト ＆ 整形JSONビューア
- 有効期限（exp）リアルタイム・カウントダウン ＆ ステータス判定（有効/期限切れ）
- 標準クレーム（iss, sub, aud, roles, scope 等）自動解説
- モックJWTトークン生成ビルダー (HS256)
- 主要認証プロバイダの実務テンプレート6選 (Auth0, Firebase, AWS Cognito, OAuth2, GitHub)
- マイ トークン保存機能

### English (en-US)
🎉 Initial release of JWT Inspector - Token Decoder & Claims Analyzer!
- 100% on-device & privacy-first JWT decoding with zero external network traffic
- Tri-color highlighting for Header, Payload, and Signature with beautified JSON
- Expiration (exp) real-time countdown and active/expired status indicator
- Standard claims glossary (iss, sub, aud, roles, scope, etc.)
- Mock JWT generator with customizable claims and HMAC-SHA256 signing
- 6 production templates (Auth0, Firebase, AWS Cognito, OAuth 2.0, GitHub, Expired)
- Local secure token bookmarks
